## ⚠️ Error Codes

| Code | Description               |
| ---- | ------------------------- |
| 0    | ✅ No error               |
| 1    | ❌ Invalid `to` number    |
| 2    | ❌ Invalid `from` number  |
| 3    | ❌ Missing required fields|
| 4    | ❌ Exceeded character limit|
| 5    | ❌ Invalid `programId`    |

<Admonition type="note" title="Note">
Always validate your request parameters before sending to avoid common errors.
</Admonition>
