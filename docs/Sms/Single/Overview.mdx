# API Overview

Welcome to the IntelSend API documentation. This API allows you to send **SMS**, **Voice**, or **Email** packets with ease. Each request handles a single communication packet.

---

## Features

- Single communication packet per request.
- Sandbox mode for testing.
- Flexible scheduling with `sendAt`.
