# API Overview

The Single Voice API allows you to send voice messages using text-to-speech for live and machine call detection. Below are the details for the endpoint, headers, request body, and response.

## Endpoint
`https://intelsend.com/api/v1/send/single_voice`

## Features

- Single communication packet per request.
- Sandbox mode for testing.
- Flexible scheduling with `sendAt`.
