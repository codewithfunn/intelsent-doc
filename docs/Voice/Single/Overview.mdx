# API Overview

The **Single Voice API** allows you to send voice messages using text-to-speech with live and machine call detection. This page provides details for the endpoint, headers, request body, and response.

---

## Endpoint

<CodeBlock language="bash">
https://intelsend.com/api/v1/send/single_voice
</CodeBlock>

---

## Features

- Single communication packet per request.
- Sandbox mode for testing.
- Flexible scheduling using `sendAt`.
