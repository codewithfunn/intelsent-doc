# FAQ

This section answers common questions about using the IntelSend Voice API.

---

### Q1: Can I send messages without `sandboxMode`?

<Admonition type="info" title="Answer">
Yes, set `sandboxMode` to `false` to send messages to production numbers.
</Admonition>

---

### Q2: What is the maximum character limit for messages?

<Admonition type="info" title="Answer">
For SMS messages, 600 characters for plain English and 300 characters for Unicode text. For voice messages, text length may vary depending on TTS limitations.
</Admonition>

---

### Q3: What is the default value of `checkOptOut`?

<Admonition type="info" title="Answer">
The default value is `true`. If `false`, the system bypasses opt-out checks for short codes (long code opt-outs are managed by carriers and cannot be bypassed).
</Admonition>
