# FAQ

This section answers common questions about using the IntelSend API.

---

### Q1: Can I send Voice without `sandboxMode`?

<Admonition type="info" title="Answer">
Yes, set `sandboxMode` to `false` to send messages to production numbers.
</Admonition>

---

### Q2: What is the maximum Voice character limit?

<Admonition type="info" title="Answer">
600 characters for plain English, 300 characters for Unicode text.
</Admonition>

---

### Q3: What is the default value of `checkOptOut`?

<Admonition type="info" title="Answer">
The default value is `true`.
</Admonition>
