#  Frequently Asked Questions

:::info
Here are some common questions developers ask about using the API.
:::

<details>
  <summary>📩 Can I send SMS without <code>sandboxMode</code>?</summary>
  <div>
    Yes, set <code>sandboxMode</code> to <code>false</code> to send messages to production numbers.
  </div>
</details>

<details>
  <summary>📝 What is the maximum SMS character limit?</summary>
  <div>
    - **600 characters** for plain English  
    - **300 characters** for Unicode text
  </div>
</details>

<details>
  <summary>⚙️ What is the default value of <code>checkOptOut</code>?</summary>
  <div>
    The default value is <code>true</code>.
  </div>
</details>
