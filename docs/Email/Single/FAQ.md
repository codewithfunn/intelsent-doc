# FAQ

### Q1: Can I send SMS without `sandboxMode`?
Yes, set `sandboxMode` to `false` to send messages to production numbers.

### Q2: What is the maximum SMS character limit?
600 characters for plain English, 300 characters for Unicode text.

### Q3: What is the default value of `checkOptOut`?
The default value is `true`.
