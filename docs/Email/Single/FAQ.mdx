#  Frequently Asked Questions (FAQ)

Here are answers to some of the most commonly asked questions about using the IntelSend API:

---

<details>
  <summary><strong>Q1: Can I send SMS without <code>sandboxMode</code>?</strong></summary>
  <div>
    ✅ Yes, set <code>sandboxMode</code> to <code>false</code> to send messages to production numbers.
  </div>
</details>

---

<details>
  <summary><strong>Q2: What is the maximum SMS character limit?</strong></summary>
  <div>
    - **600 characters** for plain English text.  
    - **300 characters** for Unicode text.
  </div>
</details>

---

<details>
  <summary><strong>Q3: What is the default value of <code>checkOptOut</code>?</strong></summary>
  <div>
    The default value is <code>true</code>.
  </div>
</details>
